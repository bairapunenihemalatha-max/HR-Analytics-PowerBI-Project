# HR Analytics Dashboard | Power BI

## Project Overview
This project focuses on analyzing employee data using Microsoft Power BI to understand workforce distribution, employee attrition, and HR-related insights.

The dashboard helps HR managers identify employee attrition patterns and make data-driven decisions to improve employee retention.

## Objectives
- Analyze overall employee strength.
- Understand employee attrition rate.
- Identify departments with higher attrition.
- Analyze attrition based on age groups and job roles.
- Understand the impact of overtime on employee attrition.
- Explore salary and employee experience patterns.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Visualization

## Dashboard KPIs
- Total Employees
- Attrition Count
- Active Employees
- Attrition Rate
- Average Monthly Income
- Average Age
- Average Experience

## Dashboard Visualizations
- Employee Attrition by Department
- Employee Attrition by Age Group
- Employee Attrition by Job Role
- Employee Attrition by Overtime
- Employee Attrition by Tenure Group
- Employee Attrition by Salary Group
- Employee Distribution by Gender

## Data Preparation
- Removed unnecessary columns.
- Checked missing values and duplicate records.
- Corrected data types.
- Created Age Group, Tenure Group, and Salary Group columns.
- Created Fact and Dimension tables for data modeling.
